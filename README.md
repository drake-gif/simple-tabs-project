Tabs Component project

A simple, accessible tabs component built with plain HTML, CSS and JavaScript. No frameworks or dependencies used.

Each tab has an animated hover effect and its own colour when selected. The matching content panel changes colour to go with it.

Project structure

index.html   # Markup for the tabs and panels
style.css    # Styling, hover effect and per-tab colours
script.js    # Tabs class: click and keyboard behaviour

Get and run the project

1. Download or clone the project.

``` git clone https://github.com/drake-gif/simple-tabs-project.git ```

2. Keep the three files in the same folder.
3. Open the project in vs code and run `index.html` and it runs in browser.
